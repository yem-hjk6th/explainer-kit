# E01: VGGT × MapAnything

Multiple images → cameras, depth and a point cloud, explained twice. VGGT (CVPR 2025): patch tokens, camera and
register tokens, alternating frame-wise / global attention, the camera and DPT heads, two ways to a point cloud.
MapAnything: the same output factored into ray directions × depth × pose × one metric scale, optional geometric
inputs, the scale token. One white dot on a synthetic 3-camera scene (`shots/scene_e01.py`, full ground truth) is
followed through every shot. 10 shots, 7:43.

| Folder | What | Shots |
|---|---|---|
| `shots/` | the full episode (`episode.json`, `storyboard.md`) | 10 |
| `pre/` | a ≤ 5 min cut (3:59) for a talk: `pre/shots/` are thin cut shells over the full-episode shots, `pre/src/*_pre.py` are forks that hide the numbers measured on the test scene (those move to Part 4); `pre/storyboard_pre.md` is generated by `pre/_tools/make_storyboard.py` | 9 |
| `pre/narration/` | the spoken script for the cut (`build_narration.py` → `narration.json`, a table, speaker-notes HTML) | – |
| `pre/voiced/` | the cut with a local TTS voice-over (4:13): generate → pick → time → render → mix → self-check, see `references/TTS.md` | 9 |
| `model_runs/` | real VGGT / MapAnything runs on the 3 test images, analysis scripts, `*_metrics.json` | – |
| `i18n_tools/` | helpers for a translated render (`--lang <code>`): box-width budgets, split / merge of the translation table, term list | – |

## Render

```bash
python -I -B -X utf8 tools/render_shot.py episodes_example/E01_vggt_mapanything/shots/s04_alt_attn.py --jobs 2
python -I -B -X utf8 tools/concat.py episodes_example/E01_vggt_mapanything
python -I -B -X utf8 tools/concat.py episodes_example/E01_vggt_mapanything/pre          # the cut
```

Voiced cut: `pre/voiced/timing.json` is shipped, so the 9 voiced shots render without TTS
(`powershell -File episodes_example/E01_vggt_mapanything/pre/voiced/render_all.ps1` renders them and writes a silent
video). The audio needs the TTS
steps first: `gen_voiced.py` (tts env, GPU) → `pick.py` (whisper) → `timing.py` → re-render → `mix.py` →
`check_voiced.py`.

## Shots that need real model output

These stop with "vggt_out.npz missing: ..." until VGGT has run: `s01_task`, `s05_heads`, `s06_two_routes`,
`s07_vggt_full`, `pre/shots/p1_vggt`, `pre/shots/p4_our_test`, and the same two in `pre/voiced/shots/`. Everything
else passes `--check-only` on a fresh clone (6 of 10 full-episode shots, 7 of 9 in the cut, 7 of 9 in the voiced cut).
The MapAnything shots read the measured numbers from `model_runs/mapanything/ma_metrics.json`, which is shipped.

```bash
# VGGT: clone github.com/facebookresearch/vggt into third_party/vggt; weights facebook/VGGT-1B (non-commercial
# licence) download on the first run
python -I -X utf8 episodes_example/E01_vggt_mapanything/model_runs/vggt/run_vggt.py third_party/vggt \
    episodes_example/E01_vggt_mapanything/shots episodes_example/E01_vggt_mapanything/model_runs/vggt
python -I -X utf8 episodes_example/E01_vggt_mapanything/model_runs/vggt/analyze_vggt.py \
    episodes_example/E01_vggt_mapanything/shots episodes_example/E01_vggt_mapanything/model_runs/vggt
# MapAnything (optional: regenerates ma_metrics.json): pip install -e third_party/map-anything (core deps only);
# weights facebook/map-anything (CC-BY-NC 4.0)
python -I -X utf8 episodes_example/E01_vggt_mapanything/model_runs/mapanything/run_mapanything.py \
    episodes_example/E01_vggt_mapanything/shots episodes_example/E01_vggt_mapanything/model_runs/mapanything
```

`s02_patchify` and `s09_ma_inputs` also compare against the official code when it is cloned into `third_party/`;
without it those checks are recorded as skipped.
